# Curso Proceso _UX/UI_ de Diseño a Código 🎨

Los códigos del proyecto de mi curso Proceso _UX/UI_ de Diseño a Código en _YouTube_. Diseñamos en _Figma_ una _landing page_ de tipo **portafolio-CV**, del boceto al prototipo, y en la última clase la llevamos a código con _HTML_, _CSS_ y _JavaScript_, de forma artesanal: sin _frameworks_ ni librerías.

> Lo grabé en 2020, con una versión anterior de _Figma_, pero el proceso es el mismo.

## Cómo usarlo

Clona o descarga el repositorio y abre `proceso-ux-ui/index.html` en tu navegador: no necesita servidor.

El formulario de contacto envía los datos con [_FormSubmit_](https://formsubmit.co/). Para recibirlos, cambia `your@email.com` por tu correo en `script.js`; la primera vez que lo uses, _FormSubmit_ te manda un correo para activarlo.
