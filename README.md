# Talleres 🛠️

Hola, soy tu amigo y docente digital **Jonathan MirCha**, bienvenid@s a mis talleres.

En este repositorio encontrarás los códigos de los talleres de mi canal de [_YouTube_](https://youtube.com/@jonmircha): proyectos prácticos que vas construyendo conmigo, de principio a fin. Algunos resuelven un tema puntual en una serie de videos cortos; otros cierran un curso, llevando a código lo que diseñamos. Cada taller vive en su propia carpeta, con su _README_.

## Talleres

| Taller                                                                                                                         | Videos | Apuntes                               | Códigos                            | Demo                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------ | :----: | ------------------------------------- | ---------------------------------- | ----------------------------------------------------------------------- |
| [Taller _PWA_: convierte tu sitio web en aplicación](https://www.youtube.com/playlist?list=PLvq-jIkSeTUYIw8CP2AP7QJs4GeeZdvs6) |   6    | [/pwa](https://jonmircha.com/pwa)     | [`pwa`](./pwa)                     | [Ver demo](https://jonmircha.github.io/youtube-talleres/pwa/)           |
| [Curso Proceso _UX/UI_ de Diseño a Código](https://www.youtube.com/playlist?list=PLvq-jIkSeTUYfCvjmlnvXcTw9eMDsbgbc)           |   11   | [/figma](https://jonmircha.com/figma) | [`proceso-ux-ui`](./proceso-ux-ui) | [Ver demo](https://jonmircha.github.io/youtube-talleres/proceso-ux-ui/) |

¿Qué hay en cada uno?

- **_PWA_**: convertimos una _landing page_ sencilla en una aplicación web progresiva que se instala en el celular y en el escritorio y funciona sin conexión.
- **Proceso _UX/UI_**: diseñamos en _Figma_ un portafolio-CV, del boceto al prototipo, y en la última clase lo maquetamos con _HTML_, _CSS_ y _JavaScript_, sin _frameworks_.

## Cómo usar los códigos

Clona o descarga el repositorio y entra a la carpeta del taller que te interese:

```bash
git clone https://github.com/jonmircha/youtube-talleres.git
```

Cada _README_ te dice si basta con abrir el `.html` en tu navegador o si necesitas algo más, como un servidor local.
